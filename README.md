# DevPad – Personal Coding and Study Workspace

DevPad is a lightweight, browser-based coding workspace designed for learners and developers. It allows users to write code, take notes, track study time, and export sessions in a single interface.

The application works completely offline and focuses on productivity without unnecessary complexity.

---

## Live Demo

https://deva-nand07.github.io/DevPad/

---

## Features

* Code editor powered by CodeMirror with syntax highlighting
* Notes panel for writing explanations and study material
* Output section for storing program results
* Light and dark themes (Eclipse and Dracula)
* Study timer with start, stop, and reset functionality
* Auto-save using localStorage
* Export full workspace (notes, code, output) as styled HTML
* Syntax-highlighted export using CodeMirror RunMode
* Responsive layout for different screen sizes

---

## Tech Stack

* HTML
* CSS
* JavaScript
* CodeMirror

No backend is required.

---

## Why DevPad

DevPad was built as a personal productivity tool to combine coding, note-taking, and revision in one place. It helps streamline the learning process by keeping everything organized and easily exportable.
